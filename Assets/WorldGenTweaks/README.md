# WorldGenTweaks
Improve world generation to be more fun (and more laggy.) Requires a world to be generated WHILE this plugin is installed. Configuration options require a reboot to take effect (or a runtime configuration manager).

## Settings:
The default settings might generate close to 10,000 islands. The map table will very likey get laggy.
20-30 clusters, with 8-10 islands per cluster will achieve somewhere near 3,000. Map table still lags some.

## Installation for playing

#### Automatic installation:
Should be as easy as installing with r2modman (or other comparable manager) and launching the modded edition.

#### Manual installation:

Copy the contents of the plugins directory the `Aloft/BepInEx/plugins` folder.
- Aloft/BepInEx/plugins/WorldGenTweaks.dll
